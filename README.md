# Ronak Taneja Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — design, colors, responsive layout, and animations
- `script.js` — mobile menu, theme toggle, scroll animations, and active navigation

## Run locally
Open `index.html` in your browser, or open this folder in Visual Studio Code and use the Live Server extension.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your real email.
- Update project GitHub links to point to each project's own repository.
